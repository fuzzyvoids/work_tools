# Podman Common

This role enables podman on a Darknet machine.

It ensures that the podman package is installed, provides redirects to common
registries on our air-gapped network, and applies other patches to enable
functionality that is limited with the default settings on our Darknet
configured machines.

You probably wont need to change anything for this, but see the defaults and
vars fles to see if anything would make sense to change.
